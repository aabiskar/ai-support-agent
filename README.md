# AI Support Agent

An AI-powered customer support agent built with Amazon Bedrock AgentCore and Strands Agents.

## Features

- MCP Gateway integration for external support tools
- Knowledge-base retrieval augmented generation (RAG)
- Cross-session customer memory
- Loyalty discount calculations using a code execution tool
- Web browsing through AgentCore Browser

## Technologies

- Python
- Amazon Bedrock AgentCore
- Strands Agents
- Model Context Protocol (MCP)

## Running locally

Install the project dependencies using the instructions in `pyproject.toml` and `README`-related course materials. AWS credentials and the required AWS resources must be configured before invoking the agent.

## Testing

Use the provided agent and browser test scripts as appropriate for the course environment.
